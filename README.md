# Beyond the Finish Line

A Python-served D3 scatterplot of Tour de France cyclist finishing times and doping allegations.

## Run locally

Requires Python 3.10 or later. No Python packages are needed.

```powershell
python app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in a browser. The app serves the chart and its dataset from the local folder. D3 is loaded from jsDelivr.
